# Gloam Privacy Policy

Effective September 2, 2026

Gloam is a local-first wallpaper app for macOS. No Gloam account is required.

## Personal media

- Videos and photo slideshows are stored locally under Gloam’s Application Support folder.
- Gloam reads only files you explicitly select with Apple’s file picker.
- Gloam does not request access to your Photos library.
- Selected photos are rendered into a local slideshow video. The original files remain where they are and are not copied into Gloam’s library.
- Gloam does not upload personal videos, photos, or rendered slideshows.

Deleting a personal scene removes its locally stored media from Gloam’s library.

## Tracking and diagnostics

The Mac app contains no advertising, behavioral analytics, or crash-reporting SDKs. Gloam does not sell personal information.

## Optional network features

- **Discover:** Catalog and search requests are sent through Gloam’s API proxy to its stock-media provider. Personal media is never included. Network providers may process standard request information such as IP address and timestamps.
- **Weather context:** Gloam does not request location during onboarding. If you explicitly enable weather context, the coordinates needed for local conditions are sent to Apple WeatherKit or Open-Meteo. Gloam does not receive or store precise location on its servers.
- **Downloads and website:** GitHub, website hosting, DNS, and security providers process ordinary network request data under their own policies.

Focus status, preferences, scene history, and other local context remain on the Mac.

## Permissions

Desktop wallpaper and photo slideshow creation do not require Full Disk Access. The optional lock-screen wallpaper feature requires Full Disk Access so Gloam can manage Apple’s wallpaper files. macOS grants this permission broadly; Gloam uses it only for wallpaper-related files and settings. You can revoke it at any time in System Settings.

## Retention and choices

Local data remains until you delete scenes or remove Gloam’s Application Support data. Service-provider network logs follow each provider’s configured retention. You can use local wallpapers without Discover, weather context, or lock-screen access.

For privacy questions, email [support@gloam.app](mailto:support@gloam.app).
